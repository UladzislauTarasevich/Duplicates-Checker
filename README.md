# Проверка дубликатов DataMatrix
Программа для поиска дубликатов кодов DataMatrix в текстовых логах производства.

## Как использовать:
1. Запустите приложение.
2. Нажмите кнопку «Выбрать папку и запустить».
3. Выберите папку с .txt файлами.
4. Программа покажет результаты проверки на экране.
